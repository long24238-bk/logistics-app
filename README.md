# 신신사 기사님 물류비 앱

기사님이 휴대폰으로 아이디·PIN을 넣고 들어와 운행 물류비를 입력하고,
관리자는 대시보드·전체 내역·엑셀(물류비신청_sgerp 양식, 기사님별 시트)·기사님 계정을 관리하는 웹앱입니다.
근태 앱과 같은 방식(GitHub + Vercel + Supabase)입니다.

## 파일 (한 앱 — 주소 하나로 기사님·관리자 모두 사용)
| 파일 | 내용 |
|---|---|
| `index.html` | 앱 시작 화면. 로그인할 때 **기사님 / 관리자**를 골라 들어감 |
| `driver.js` | 기사님 화면 (운행 입력, 내 내역, PIN 변경) |
| `admin.js` | 관리자 화면 (대시보드, 기사님 등록, 운행 내역·대리 입력, 엑셀, 설정) — PC는 왼쪽 메뉴, 폰은 아래 탭 |
| `core.js`, `style.css` | 함께 쓰는 기능과 디자인 |
| `admin.html` | 예전 관리자 주소로 들어오면 앱으로 넘겨 줌 |
| `shinshin-logo.png`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 신신사 로고와 홈 화면 아이콘 |
| `manifest.webmanifest`, `sw.js` | 홈 화면에 앱처럼 추가(설치)하기 위한 파일 |
| `config.js` | Supabase 연결 정보 + **출발지 목록, 납품거래처 목록** (여기서 추가/삭제) |
| `supabase_setup.sql` | Supabase에 실행하는 설치 SQL (표·로그인 함수·처음 계정) |

## 설치 순서
1. **Supabase** → 근태 앱 프로젝트(attendance-app)를 열고 SQL Editor → New query →
   `supabase_setup.sql` 내용을 전부 붙여 넣고 **Run**. (이름이 모두 `lg_`로 시작해서 근태 앱과 겹치지 않습니다)
2. Supabase → Project Settings → API에서 **Project URL**과 **Publishable key**를 복사해 `config.js`에 붙여 넣기.
3. **GitHub**에 새 저장소(예: `logistics-app`)를 만들고 폴더 안 파일 15개를 모두 올리기.
4. **Vercel** → Add New → Project → 그 저장소 Import → Deploy.
   나온 주소 하나를 기사님과 관리자가 함께 씁니다 (로그인 화면에서 기사님/관리자 선택).

## 처음 계정
- 관리자: 아이디 `admin` / 비밀번호 `shinshin1234` → 처음 로그인하면 새 비밀번호(6자 이상)로 바꿔야 합니다.
- 기사님 8명: 아이디 = 이름(예: `김희정`) / 처음 PIN `0000` → 처음 로그인하면 본인 PIN(숫자 4~6자리)으로 바꿉니다.

## 이미 설치했다면
`supabase_setup.sql`을 한 번 더 실행하면 연락처·차량번호·메모 칸과 6개월 추이 기능이 추가됩니다. 기존 데이터는 그대로입니다.

## 보안
- 표는 앱에서 직접 읽을 수 없고, 로그인 토큰을 확인하는 함수로만 접근합니다.
- 기사님은 본인 내역만 보고 고칠 수 있습니다. 관리자는 전체를 봅니다.
- PIN·비밀번호는 암호화(bcrypt)해 저장하고, 5번 틀리면 10분 잠깁니다. 관리자가 PIN을 초기화하면 바로 풀립니다.

## 계산
- 운행비 합계 = 횟수 × 회당운행비
- 유류비합계 = 횟수 × 유류비지원금
- 정산액 = 운행비 합계 + 유류비합계 + 야간수당

## 출발지·납품거래처 목록 고치기
`config.js`의 `LG_ORIGINS`(출발지), `LG_DESTS`(납품거래처) 목록에 줄을 추가하거나 지운 뒤 GitHub에 다시 올리면 됩니다.
기사님은 이 목록에서만 고를 수 있고, 거래처 칸은 없앴습니다 (엑셀의 거래처 열은 양식 유지를 위해 빈칸으로 남김).
